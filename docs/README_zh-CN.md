# SinkingStarSketchPad 3.4.5

《沉星之序》的游戏内绘图与路线标记工具。提供星芒鼠标光标、画笔、几何图形、文字、三页草稿和自动吸附格心的路径。通过原生 64 位 ReShade 插件绘制到 DirectX 12 游戏画面。

**当前为 Beta。** 用户已确认所测关卡的原生预览与地面标记可用；本次网格绘画、预览和两次点击绘图扩展仅做静态检查与编译，实际贴合和操作体验仍需游戏内确认。

## 安装和升级

本包采用手动复制安装，不包含也不需要 CMD、批处理、PowerShell 或 EXE 安装程序。简明步骤见 **安装说明.txt**。

首次安装且没有其他 ReShade / 图形代理时：保存进度并完全退出游戏，解压发布包，将 `game_files` **里面的内容**复制到包含 `sinking_star.exe` 的目录，保持以下结构：

```text
sinking_star.exe
dxgi.dll
SinkingStarSketch.addon64
ReShade.ini
SinkingStarSketch-assets/
  NotoSansCJKsc-Regular.otf
```

不要把整个 `game_files` 文件夹原样放在 EXE 旁。启动游戏后按 E 打开绘图。

升级时，先将旧插件、字体、`ReShade.ini` 与 `SinkingStarSketch-data` 备份到游戏目录之外，再复制新插件和字体。保留草稿、偏好和原配置；手动编辑 `ReShade.ini` 中已有 `[INPUT]` 节，把 `InputProcessing` 的值改为 `1`，不要重复添加键。没有该节时添加：

```ini
[INPUT]
InputProcessing=1
```

该值用于分别处理键盘和鼠标；`2` 会继续屏蔽绘图时的键盘，`0` 会让绘图鼠标影响游戏。本包不会自动备份、修改配置或检测冲突，需按上述步骤自行完成。

已有 ReShade 或其他图形代理时，保留原运行库，先阅读英文说明的 Existing ReShade installations，不要强行覆盖。本版只验证了附带的 ReShade 6.8.0 完整插件运行库。

## 中英文切换

工具栏 **Language / 语言** 菜单提供 System、English 和简体中文。System 在中文 Windows 界面语言下显示中文，其余使用英文。选择立即生效，重启后保留。

设置文件为游戏目录中的 `SinkingStarSketch-data/settings.ini`：

```ini
[Interface]
Language=zh-CN
```

还可填写 `en` 或 `auto`。切换的是 Mod 界面和通知，不会翻译你输入的文字或游戏本身。ReShade 的 Home 面板语言单独管理。

## 常用操作

| 操作 | 按键 |
| --- | --- |
| 进入/退出绘图 | E |
| 指针显隐 / 草稿显隐 | G / B |
| 取消笔画或文字；否则返回游戏 | Esc |
| 画笔 / 直线 / 箭头 | Alt+P / Alt+L / Alt+A |
| 矩形 / 椭圆 / 文字 | Alt+R / Alt+O / Alt+T |
| 整笔橡皮 / 格子路径 | Alt+K / Alt+H |
| 绘图 | 按住左键拖动 |
| 直线 / 箭头 / 矩形 / 椭圆 | 也可点击起点再点击终点；右键取消待定图形 |
| 平面升高 / 降低一格 | 绘图打开时在画布滚动滚轮 |
| 五种笔色 | Alt+1–5 |
| 45 度直线、正方形或正圆约束 | 按住 Shift |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y；无待定图形且自由相机关闭时也可右键撤销 |
| 三页草稿 | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| 保存 / 清空本页（可撤销） | Ctrl+S / Ctrl+Shift+Delete |
| 完成文字 | Ctrl+Enter |

E/G/B 只在不按 Ctrl/Shift/Alt 且没有文字输入框时触发。已核对游戏默认按键，自定义游戏键位可能冲突。绘图时普通键盘输入会继续交给游戏，可操作角色和镜头。工具改为 Alt+字母、选色改为 Alt+1–5，避免移动时误切工具。文字输入框打开或按住 Ctrl/Alt 使用 Mod 组合键时会暂时接管键盘；自定义游戏组合键仍可能冲突。鼠标由绘图接管，若需使用游戏鼠标操作，请按 E。切出游戏会保留绘图模式和未完成文字，完成实际拖绘，取消待定的两次点击图形并保存已完成笔迹；切回后松开鼠标按键即可继续，避免把切换窗口的点击画进草稿。

## 实验性自由相机

进入关卡后按单键 **T**，或点击绘图工具栏的“自由相机”。每次启动默认关闭，需要先连接可验证的游戏主相机。鼠标悬停在面板上时，WASD 仍可移动；右键拖动和滚轮请在面板外操作。相机模式会显示鼠标指针；编辑文字或调整控件时暂停相机快捷操作。该功能与现有绘图、路径共存，不需要第二个项目或 Mod。

| 操作 | 按键 |
| --- | --- |
| 地面平移 | W/A/S/D |
| 升高 / 降低 | Q / Z |
| 加速移动 | 按住 Shift |
| 围绕捕获的焦点旋转、俯仰 | 按住右键拖动 |
| 镜头缩放 | 关闭绘图后在画布滚动滚轮 |
| 绘图工具栏开关 | E |
| 相机开启时撤销笔迹 | Ctrl+Z |
| 恢复游戏视角并关闭自由相机 | Esc、T 或面板按钮 |

相机面板新增独立的 **反转鼠标 X 轴** 和 **反转鼠标 Y 轴**：X 改变右键横向拖动的旋转方向，Y 改变纵向拖动的俯仰方向，不影响 WASD、升降键或滚轮。默认均关闭。移动速度、鼠标灵敏度和两个反转开关自动保存到 `SinkingStarSketch-data/settings.ini`，重新开启相机、重启游戏后仍保留；重置视角也不会清除这些偏好。

默认移动速度从 12 降至 3 世界单位/秒，鼠标灵敏度从 0.30 降至 0.08 度/像素，Shift 为 2 倍速度，滚轮每格缩放 6%。俯仰在俯视顶部和距离地平线 5 度的位置停止，保持原视角所在一侧；WASD 地面移动方向只跟随水平旋转，避免俯仰导致方向翻转。

相机面板还提供 X/Y/高度偏移、旋转、俯仰、缩放和重置到当前游戏相机。开启时键鼠由相机和绘图接管，WASD 不再移动人物；输入文字时暂停移动。检测到场景或原相机大幅跳变时可能自动关闭。关闭后恢复原有键盘操作游戏的行为。格子路径使用同一套覆盖后的相机投影，仍固定在原格子上；普通画笔和文字仍固定在屏幕上；开启“网格绘画”后创建的笔迹和文字锚点会跟随世界。

**这是实验性渲染相机覆盖**：修改当前提交绘制命令引用的、经过校验的 DirectX 12 相机常量，不会修改游戏 CPU 侧的场景相机。原有裁剪、阴影、反射、可见性/加载和鼠标选取可能仍使用原视角；大幅平移、低角度或看向原来不可见的区域时，可能缺少物体或出现视觉异常。不会解锁未加载关卡，也不会暂停游戏。需要时恢复游戏视角；实际关卡的完整一致性尚待实测。

## 网格绘画与预览

点击“网格绘画”切换新笔迹的坐标空间。画笔和椭圆使用连续平面坐标；直线、箭头、矩形起终点自动就近吸附格心或交点，Shift 约束也在平面内计算。文字锚点跟随世界，文字保持正向和固定屏幕字号。橡皮依据当前投影擦除整条笔迹，路径规则不变。每条笔迹独立保存创建时的平面、颜色和笔宽。

“网格预览”可叠加中心点、交点、边框和棋盘填充，覆盖指针附近 11×11 格，可调透明度，不挖墙体遮挡。每次成功标定另有两秒棋盘提示，只挖穿入实心体素内部的格子，最多 128×128 格。绘图打开时画布滚轮每格升降平面一单位。完整规则及草稿升级见[网格绘画说明](GRID_DRAWING.md)。

## 固定在格子上的路径

进入关卡，三页使用同一次当前控制角色读取结果初始化平面，直接采用逻辑 Z 原值；不要求脚下有地面，也不比较或取整高度。之后每页独立固定目标。按 E → Alt+H 选择路径；“设为角色所在平面”按钮可重新读取角色并修改当前页，读取失败时保留目标。请等待有效游戏相机后绘制路径。

“手动标记”与角色按钮同时展示，无需切换模式。点击后先在后台刷新一次原生地形，再左键点击可见地面格：成功后自动结束标记；墙面、空处或读取尚未完成时提示并继续等待。画布中键始终快速标记一次，保存按下时的指针和相机，刷新后完成标定，无论成功与否均结束标记，保留当前工具。Esc、换页、切换工具或新请求会作废旧请求。绘图打开时画布滚轮每格将目标 Z 加 / 减 1，保留原小数部分；关闭绘图后用于自由相机缩放。详见[地面标识说明](MANUAL_GROUND.md)。

换关卡后重新初始化三页目标，已绘路径保留各自的网格。平时仅约每秒检查关卡身份；角色初始化成功后不再连续采样，地形仅在进入关卡或标记请求时读取。备用 GPU 相机采集已禁用，当前有效相机和自由相机所需处理保留。遮挡仅检查原生实心墙体，不包含装饰模型、升降台和莲叶等额外支撑来源。

开启“网格预览 → 中心点”，确认吸附点与地面一致，再点击格心开始路径；点击同一行或同一列的格子，沿途格心会连接。转弯处先加一个点；不接受直接跨向斜格。点击“结束路径 / 新路径”后可画另一条路线。

按 E 返回游戏后，路径根据游戏相机重新投影。每条路径保存自己的世界格子基准，后续识别变化不会移动旧路径。右键/Ctrl+Z 撤销最近一次添加并结束当前路径，Alt+K 选择橡皮，可擦除整条路线。

该工具只标记路线，不会检查障碍、自动寻路、移动人物或推箱子。普通绘画固定在屏幕坐标；开启“网格绘画”后创建的画笔、图形和文字锚点会跟随世界。不同关卡请使用不同草稿页；页面不会自动按关卡名称分配。特殊斜面、楼层、过渡镜头、环绕地图和游戏更新后的表现需要实际核对。

## 光标

普通模式为浅金晶刃指针，带深色边缘和星芒刻纹；绘图为镂空星芒准星，中心提示笔色；橡皮为镂空符文圆环。尖端或准星中心对应鼠标位置，较高分辨率下会适当放大。

## 保存、导出和卸载

草稿位于游戏目录 `SinkingStarSketch-data/drafts.txt`，上一版为 `.bak`；语言、相机、网格绘画和预览偏好保存到同目录的 `settings.ini`。工具栏“导出 SVG”写入 `exports` 子目录，世界笔迹与显示、橡皮使用同一当前相机投影；没有有效相机时会省略世界笔迹，未完成图形不会导出。每页最多 2000 条笔迹、合计 120000 个点、60 步撤销；撤销历史不跨重启保存。

草稿格式升级为 **v3**，继续读取 v1/v2，为每条笔迹保存网格。首次升级旧草稿前会保留不覆盖的 `drafts.pre-v3.txt`；备份失败则停止保存。交给旧插件前需恢复该升级备份；常规 `.bak` 仍保存上一次内容。

卸载时退出游戏，把 `SinkingStarSketch.addon64` 移到游戏目录之外即可停用。保留 `SinkingStarSketch-data`，以保留草稿、语言偏好与导出。

如需一并移除首次安装附带的 ReShade，先确认没有其他 Mod 共用，再移出本包的 `dxgi.dll`、`ReShade.ini` 与字体资源。原有图形设置可从备份恢复。不需要卸载脚本。

已有 ReShade 时仅复制插件和字体，保留现有运行库和其他配置，手动将 `[INPUT] InputProcessing` 设为 `1`，并确认从游戏目录加载插件。

## 排错和第三方组件

没有工具栏时确认安装在实际运行的 EXE 旁，完全重启游戏后按 E。格子或相机一直等待时进入普通关卡稍候，不要假定任意网格就是实际地面。

升级后中文缺字时，请检查保留的原 `ReShade.ini`：请在 ReShade 字体设置中选择 `SinkingStarSketch-assets/NotoSansCJKsc-Regular.otf`。日志为 `ReShade.log` 和 `SinkingStarSketch-data/status.txt`；公开提交前请检查其中的个人路径。
