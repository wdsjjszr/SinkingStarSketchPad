SinkingStarSketchPad 3.4.6 — Manual installation

No CMD, batch, PowerShell or executable installer is included or required.

FRESH INSTALL (no existing ReShade or graphics proxy):
1. Save your progress and completely exit the game.
2. Extract this ZIP to a normal folder.
3. Open the game folder containing sinking_star.exe. Back up any existing graphics-mod files before making changes.
4. Copy the CONTENTS of game_files into that folder:
   dxgi.dll
   SinkingStarSketch.addon64
   ReShade.ini
   SinkingStarSketch-assets\NotoSansCJKsc-Regular.otf
   Keep the SinkingStarSketch-assets folder intact. Do not copy only the font or place the game_files folder itself next to the executable.
5. Start the game. E opens drawing; G toggles the cursor; B toggles marks. Alt+letter selects tools; Alt+H selects paths.

UPGRADE / EXISTING RESHADE:
1. Exit the game. Back up the old add-on, ReShade.ini, font assets, and SinkingStarSketch-data folder outside the game folder.
2. Copy SinkingStarSketch.addon64 and the SinkingStarSketch-assets folder from game_files into the game folder. Preserve SinkingStarSketch-data.
3. Keep your existing dxgi.dll and ReShade.ini. Only the bundled ReShade 6.8.0 full add-on runtime is tested; verify a different ReShade setup before using it. Do not overwrite an unknown graphics proxy.
4. Open your ReShade.ini in a text editor. Under the existing [INPUT] section, set InputProcessing=1 (replace the old value; avoid duplicate entries). If [INPUT] is absent, add:
   [INPUT]
   InputProcessing=1
   Mode 2 blocks the keyboard during drawing. Mode 0 lets drawing mouse input affect the game.
5. Ensure ReShade loads add-ons from the game folder. For missing Chinese glyphs, choose SinkingStarSketch-assets/NotoSansCJKsc-Regular.otf in ReShade's font settings, then restart the game.

UNINSTALL / DISABLE:
Exit the game, then move SinkingStarSketch.addon64 outside the game folder. This disables the sketchpad. Preserve SinkingStarSketch-data to keep drafts, preferences and exports.
If you also want to remove a fresh installation's bundled ReShade, move its dxgi.dll, ReShade.ini and font assets outside the game folder only after confirming that no other mod uses them. Restore your previous graphics setup from your backup if applicable.

This release adds an experimental free camera to the native add-on. Read README_EN.md for full controls, requirements and compatibility limits.

FREE CAMERA (EXPERIMENTAL): T toggles. WASD pans, Q/Z moves up/down, Shift speeds up, with drawing closed right drag rotates/tilts and wheel zooms, T/Esc leaves controls according to Keep view; Restore game view always restores the native camera. E toggles drawing. Camera mode reserves keyboard/mouse input; Ctrl+Z undoes annotations. Large view changes can reveal original-game culling/shadow/reflection limits. Read README_EN.md.

3.4.6: Gentler movement/rotation/zoom, tilt limits, and separate Invert mouse X / Invert mouse Y checkboxes in the camera panel. Speed, sensitivity and axis preferences save automatically.

## Upstream camera integration — 3.4.6

New or missing camera settings default to speed 5, Y inversion on and Keep view on. Existing speed and axis preferences remain. T/Esc leaves controls and releases input while retaining the view when enabled; T resumes. Restore game view always restores the native view, with a button in the drawing toolbar while held. Retained views reset on restart or a native scene change. Drawing, native picking and voxel clipping continue using the effective camera position/direction. The full font-bearing manual package is retained.
